# DUDESIGN

**Product design partner for AI startups.**

We decide what to build, design it, and we implement the interface.

## Run the deck

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — arrow keys / space to navigate.

## Personal portfolio

Paulo's job-application portfolio lives in [`portfolio/`](portfolio/) and deploys to **[paulo.dudesign.us](https://paulo.dudesign.us)** from this repo (Vercel Root Directory: `portfolio`).

```bash

npm run portfolio:dev       # http://localhost:3001
```

Local preview through the deck: [http://localhost:3000/paulo](http://localhost:3000/paulo) (requires portfolio dev server on 3001).
